What you get

Two layers. The library is topic guides, interview Q&A, critical clarifications, quick refs, and logic charts. The gym is Start (baseline diagnostic), Practice, Scenarios, OTM Lab, and Dashboard.

Audience is senior and staff-level appsec / product security, but mid-level folks use the same paths if they pick the 21-day intensive or AppSec track.

First hour

  1. Open Start. Pick role, interview horizon, and stack. Under 3 weeks routes you to the intensive path on purpose.
  2. Speak eight prompts out loud (90 seconds each). Score 0 blank, 1 partial, 2 crisp with trade-offs. Honesty beats ego here.
  3. Say whether you have three workable behavioral stories. Save the path. Open the first gap topic or drill it in Practice.
  4. Glance at Dashboard. Next recommended, due reviews, and weak drills all feed off what you just did.

Each mode

Start

Baseline diagnostic from the Interview Preparation docs, turned into a product loop. Output: recommended path, gap topic list, confidence seeds on weak areas.

Open Start →

Practice

Pick a topic with an Interview Q&A deck. Timer runs. You talk. Then self-score Accuracy, Structure, Depth, Time (0-2 each, /8). Reveal the model answer after you score, not before. Weak averages show up on the Dashboard.

Open Practice →

Scenarios

Longer prompts: architecture review, incident response, threat model, assessment, design. Use the task checklist while you talk. Score Clarify / Prioritize / Controls / Communicate. Model frameworks come from the Practice Exercises and Product Real-World Scenarios guides.

Open Scenarios →

OTM Lab

Sample Open Threat Model style systems (payment flow, SaaS mesh, public bucket mishap). Read the Mermaid graph, threats, and JSON. Drill interview prompts that force you to point at zones and flows by id. Text graph stays under a disclosure if the diagram fails to load.

Open OTM Lab →

Dashboard

Path picker, next recommended topic, due-for-review queue (spaced by confidence), weak Practice / Scenarios / OTM lists, completion charts. Export JSON before you clear site data. Import restores it.

Topic library

From Topics, search by name or full text across guides and Q&A. Hit a snippet and you jump into that file type. Per topic you usually get:

  • Comprehensive Guide
  • Interview Questions & Answers
  • Critical Clarification
  • Quick Reference
  • Logic Chart (interactive mind map)

Mark modules complete as you go. Set confidence 1-5 and hit Mark reviewed so spaced review knows when to bring the topic back (about 1 day at shaky, up to 14 days when you can teach it).

Tip: if you only read, you will feel busy and still blank in a live interview. Pair each new guide with one Practice loop the same day.

How scoring works

Self-score is the point. No server grades you. Totals map roughly to Weak / Developing / Strong / Interview-ready. Low scores should send you back to the guide or Critical Clarification, not to another random topic.

Practice and OTM use a /8 rubric. Scenarios use Clarify, Prioritize, Controls, Communicate. Same idea: name the system, order the risk, propose a control you can verify, say who you tell.

Progress and privacy

Everything saves in localStorage on your machine (interview_prep_progress_v2). No account. Clearing browser data wipes it unless you exported first.

  • Dashboard → Export downloads JSON.
  • Import on another browser or after a reset.
  • Reset progress is hard delete of local gym state.

A simple weekly loop

  1. Monday: Dashboard due list + one Practice deck from a gap topic.
  2. Midweek: one Scenario (IR or architecture) with the timer.
  3. Later in the week: one OTM model drill, then teach the graph out loud.
  4. Before interviews: Quick Refs only on topics at confidence 4-5; deep dive only on Due or Weak rows.

If the horizon is under three weeks, stay on the intensive path and skip encyclopedic reading. Fail a prompt, fix that topic, move on.
